# Ordo

Ordo is a dark-first, minimal [Obsidian](https://obsidian.md) theme: cold grays without pure black or white, depth from soft shadows and radius, and content that dims at rest and brightens on focus.

## Installation

From the Community themes browser:

1. Open **Settings → Appearance → Themes → Manage**.
2. Search for **Ordo**.
3. Click **Install and use**.

### Manual

1. Download `theme.css` and `manifest.json` from the latest [release](https://github.com/LubrieDev/ordo/releases).
2. Put both files in `<vault>/.obsidian/themes/Ordo/` and restart Obsidian.

## Usage

Select **Ordo** under **Settings → Appearance → Themes**. It supports both dark and light base color schemes and requires **Obsidian 1.13.0+**.
